# Security policy

## Reporting a vulnerability

Email **security@socialreins.com**. Please do not open a public issue, pull request or discussion for a security problem.

Include what you found, how to reproduce it, and what an attacker could do with it. We will acknowledge your report, keep you updated while we work on a fix, and credit you in the release notes if you want.

## Scope

This policy covers every repository in the [socialreins](https://github.com/socialreins) organization and the hosted service at socialreins.com.

## Supported versions

SocialReins has no stable release yet. Fixes go to the `main` branch of each repository.
