# SocialReins brand

The mark is three reins gathered into one brass ring: every social account, held in one hand.

| File | Use |
|---|---|
| `logo.svg` | The mark on a rounded pine tile. Default everywhere. |
| `logo-square.svg` | Full-bleed square tile, for app icons that get rounded by the platform. |
| `avatar-512.png` | GitHub org and social profile avatar. |
| `social-card.png` | 1200x630 link preview image. |

Colors: pine `#17352a`, paper `#f7f9f3`, brass `#c99a2e`, saddle `#7b3f1e`, field `#dfe6dc`. Wordmark: "SocialReins" in Bricolage Grotesque ExtraBold.

Keep clear space of at least a quarter of the mark's width around it. Do not recolor, stretch or add effects.
