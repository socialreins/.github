# SocialReins brand

The mark is a speech bubble with an orange rein running through it: every conversation, held in one hand.

| File | Use |
|---|---|
| `logo.svg` | The mark on a rounded ink tile. Default everywhere. |
| `logo-square.svg` | Full-bleed square tile, for app icons that get rounded by the platform. |
| `avatar-512.png` | GitHub org and social profile avatar. |
| `social-card.png` | 1200x630 link preview image. |

Colors: ink `#121212`, signal orange `#ff5b22`, deep orange `#c2330a` (text, focus rings), canvas `#faf8f6`, paper `#ffffff`, soft ink `#57534e`. Wordmark: "SocialReins" in Bricolage Grotesque ExtraBold.

Signal orange is for marks, buttons with ink text, and accents. For orange text on light backgrounds use deep orange, since signal orange is under AA contrast there.

Keep clear space of at least a quarter of the mark's width around it. Do not recolor, stretch or add effects.
