# SocialReins

Open-source social media manager. Publish and schedule to Facebook Pages, Instagram, Threads, LinkedIn, Bluesky and X, take down published posts, and drive it all from a REST API or an MCP server.

Start at [socialreins/web](https://github.com/socialreins/web), the main repo, for install and self-host docs. The API server is [socialreins/brain](https://github.com/socialreins/brain). Join the hosted waitlist at [socialreins.com](https://socialreins.com).
