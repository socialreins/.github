# SocialReins

Open-source social media manager. Publish and schedule to Facebook Pages, Instagram, Threads, LinkedIn, Bluesky and X, take down published posts, and drive it all from a REST API or an MCP server.

Start at [socialreins/socialreins](https://github.com/socialreins/socialreins). Join the hosted waitlist at [socialreins.com](https://socialreins.com).
